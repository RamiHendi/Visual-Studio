# Rami Hendi's Visual Studio | Portfolio & Live CV

A modern React & Vite application for **Rami Hendi's Visual Studio**, showcasing senior 3D architectural visualization, interior & kitchen design, mechanical product modeling, and technical art automation.

## Features

- **Studio Showcase**:
  - Dynamic folder and category filtering (Architectural Visualization, Interior & Kitchen Design, Product & 3D Modeling, Animations & Technical Tools).
  - Instant live keyword search (by title, technical description, category).
  - Masonry and Uniform Grid layout switchers.
  - Interactive cards with badges, video overlays, and hover metadata.

- **Interactive Curriculum Vitae**:
  - Live structured rendering from Google Docs (Executive Summary, Work Experience timeline with dates and positions, Technical Skills tag cloud, Education & Certifications).
  - Browser print view optimization and direct PDF export.

- **Headless Google Workspace CMS Connection**:
  - Connects to Google Drive folders and Google Docs via Google Apps Script Web App API.
  - Local caching with sessionStorage for instant loads.
  - Complete Google Apps Script template code with one-click copy and folder hierarchy blueprint.

- **4K Lightbox & Video Theater**:
  - High-resolution modal with smooth 4K zoom (1.65x), aspect-ratio preserving video embeds, external links, previous/next buttons, and keyboard controls (Arrow keys, Esc).

## Tech Stack

- **React 19** with **TypeScript**
- **Vite 6**
- **Tailwind CSS v4**
- **Font Awesome & Google Fonts** (Inter, Space Grotesk, JetBrains Mono)
